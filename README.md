# BJJ Learn 🧠

**BJJ Learn** est un petit générateur de leçons aléatoires de Jiu-Jitsu Brésilien (JJB).  
Chaque clic sur le bouton affiche une technique ou un concept différent pour apprendre le JJB facilement.

## Fonctionnalités

- Affiche une leçon aléatoire à chaque clic.
- Interface simple et épurée.
- Projet entièrement en HTML, CSS et JavaScript.

## Utilisation

1. Ouvrir `index.html` dans un navigateur.
2. Cliquer sur le bouton **"Leçon du jour"** pour découvrir une nouvelle leçon.
3. Profiter et apprendre une nouvelle technqiue de JJB à chaque clic !

## Technologies

- HTML
- CSS
- JavaScript
